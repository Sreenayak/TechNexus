#  TechNexus — Tech Event Management Portal

> Discover. Register. Connect. Innovate.

EventForge is a responsive web-based Tech Event Management Portal designed to help students easily discover and register for technical events.

The project is developed as part of **CodeForge WebSprint 2026** and focuses on providing a simple, attractive, and user-friendly experience for finding and registering for technical events.

---

##  Problem Statement

Design and develop a responsive web application that helps students discover and register for technical events.

The application should provide an attractive home page, event listings, search and filtering options, and an easy-to-use registration system.

The project is developed using:

- HTML
- CSS
- JavaScript

No backend.

---

## Project Objectives

The main objectives of EventForge are:

- Help students discover technical events easily.
- Display important event information in one place.
- Allow users to search events by name.
- Allow users to filter events by category.
- Provide a simple event registration form.
- Validate registration details.
- Provide a responsive experience on different devices.
- Create an attractive and modern user interface.

---

##  Features

###  1. Home Page

The home page contains:

- Attractive hero section
- Introduction to the platform
- Event highlights
- Call-to-action button
- Modern and responsive UI

###  2. Event Listing

The portal displays multiple technical events.

Each event contains:

- Event Name
- Date
- Category
- Description
- Register Button

The application includes at least **6 technical events** as required by the problem statement.

###  3. Search & Filter

Users can easily find events using:

- Search by event name
- Filter by event category
- Dynamic event results

###  4. Event Registration

Users can register for an event by providing:

- Name
- Email
- College
- Event Selection

The registration form includes input validation to ensure that the required information is entered correctly.

###  5. Responsive Design

EventForge is designed to work across:

-  Mobile
-  Tablet
-  Desktop

The layout automatically adapts to different screen sizes.

---

#  Bonus Features

EventForge also includes additional features to improve the user experience.

###  Dark Mode

Users can switch between:

- Light Mode
- Dark Mode

###  Local Storage

Registration information and user preferences can be stored using browser Local Storage.

This allows data to remain available even after refreshing the page.

###  Animated UI

The website includes smooth animations and transitions to make the interface more attractive and interactive.

###  Custom Feature

A custom feature can be added to improve the overall event experience.

Examples:

- Event countdown
- Upcoming events section
- Registration success popup
- Event statistics
- Favorite events
- Event details modal
